# IA Locale Studio — Android natif expérimental
Préversion indépendante du PC, sans compte ni serveur d'inférence distant.
Texte et Code : llama.cpp b6000 en CPU, import local de GGUF (commencer par 1–3B Q4). Aucun modèle inclus. ARM64 et x86-64, Android 8+. Internet requis pour récupérer les modèles depuis Hugging Face (navigateur), puis import via le sélecteur Android. Image crée une illustration vectorielle PNG (768 × 768), Vidéo une animation H.264 (384 × 384, trois secondes à 12 images/s) et Musique une mélodie WAV mono (22 050 Hz). Le GGUF produit la scène ou la partition à partir de la demande. Les fichiers sont rendus sur le téléphone. L’historique permet de rouvrir et de supprimer une création. « Exporter la création » enregistre une copie à l’emplacement choisi.
Compilation : Android SDK 35, NDK 27.2.12479018, CMake 3.22.1, JDK 17, Gradle 8.9. Le workflow produit un APK debug pour essais, pas une release signée avec une clé pérenne. Aucune clé privée n'est stockée dans le dépôt. Les tests JVM ne prouvent pas la génération réelle sur téléphone.
